## 版本说明

### v1.0.0（当前）

首个独立重构发布版，采用 B/S 架构（FastAPI 后端 + React 前端），完全脱离原 CAI 框架依赖。

核心能力：
- 单模型配置（任意 OpenAI 兼容端点）
- 20+ 安全智能体 + 11 个工具
- 多智能体编排与渗透测试流水线
- 实时思考过程展示 + 工具调用可视化
- 可配置滑动窗口上下文管理（节省 token）
- 一次性登录凭证安全认证

后续文档（智能体说明、API 参考、架构设计等）将在此目录逐步补充。
