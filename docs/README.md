## v1.3.1 版本亮点

1. **对话稳定性**：SSE 心跳保活 + 流式事件独立处理，长时工具执行不再断连、工具增量不丢失。
2. **中断续跑**：工具调用链无损重建，「继续」可基于已执行进度续跑，避免从头重跑。
3. **经验库修复**：scope 规范化，解决「创建成功但库中不增加」。
4. **安全加固**：附件路径穿越防护、文件监听线程竞态修复。

## v1.3.0 版本亮点

1. **经验系统**：对话经验自动向量化、语义检索命中，提供长期记忆。
2. **护栏 Guardrails**：文件化输入/输出合规策略，注入防护。
3. **接收器**：Webhook / Syslog / 文件监听，打通外部事件源。

## 快速开始

```bash
./setup.sh     # 安装环境
./start.sh     # 启动服务（后端 8001 / 前端 5173）
```
