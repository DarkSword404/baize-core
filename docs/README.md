## 版本说明

### v1.2.0（当前）

采用 B/S 架构（FastAPI 后端 + React 前端）。

核心能力：
- 单模型配置（任意 OpenAI 兼容端点）
- 30 个安全智能体 + 11 个工具
- Agent Builder 对话式创建自定义智能体
- 实时思考过程展示 + 工具调用可视化
- 可配置滑动窗口上下文管理（节省 token）
- 一次性登录凭证安全认证
- 修复对话刷新后空消息问题

后续文档（智能体说明、API 参考、架构设计等）将在此目录逐步补充。
