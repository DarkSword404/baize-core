## v1.3.0 版本亮点

1. **经验系统**：对话经验自动向量化、语义检索命中，提供长期记忆。
2. **护栏 Guardrails**：文件化输入/输出合规策略，注入防护。
3. **接收器**：Webhook / Syslog / 文件监听，打通外部事件源。

## 快速开始

```bash
./setup.sh     # 安装环境
./start.sh     # 启动服务（后端 8001 / 前端 5173）
```
